# Changelog

## 1.0.5

- Initial public release.
- Independent speed multiplier for each supported timed crafting machine.
- Added in-game configuration support through BepInEx configuration entries.
- Added English machine names followed by the game's localized name.
- Removed internal prefab names from the configuration interface.
- Restricted detection to actual timed crafting machine types.
- Added support for Deep North machines.
